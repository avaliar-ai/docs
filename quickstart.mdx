There are **two ways** to put Avaliar in front of your LLM traffic. Pick the one
that fits your stack.

<CardGroup cols={2}>
  <Card title="Proxy API" icon="server">
    Route your LLM calls through Avaliar's endpoint. **No SDK, no code changes**:
    swap your provider URL and add your Avaliar key. Works with any language.
    <br />Best for: quick setup, non-Python apps.
  </Card>
  <Card title="Python SDK" icon="python">
    An open-source runtime guard inside your app. It checks every message, tool
    call and reply against a policy you own, and records every decision.
    <br />Best for: Python apps and agents, offline or private data, no account.
  </Card>
</CardGroup>

## Which should I use?

| | Proxy API | Python SDK |
| --- | --- | --- |
| **How you integrate** | Change your endpoint URL | Call the guard's checks, or add one line for your agent framework |
| **Language** | Any (HTTP) | Python 3.11+ |
| **Where checks run** | Avaliar's cloud | Inside your process: rules, local models, an optional deep check |
| **What is checked** | Prompts and responses | Input, output, tool calls, tool results and actions |
| **Blocks prompt injection** | Yes, before it reaches the LLM | Yes, before it reaches your model |
| **Account** | Pro plan | None; an `sdk` key adds your team's dashboard |

<Tip>
  Not sure? In Python, start with the **SDK**: it runs offline with no account,
  and one environment variable links it to the dashboard later. For zero code
  changes or another language, use the **Proxy API**.
</Tip>

## Set up your method

The Proxy needs an API key from the [Avaliar Dashboard](https://app.avaliar.ai)
with the `proxy` scope. The SDK needs no key to run; an `sdk` key links it to the
dashboard.

<Tabs>
  <Tab title="Proxy API">
    The proxy exposes an **OpenAI-compatible** endpoint, so any OpenAI SDK or
    no-code tool works by just changing the base URL: no provider keys in your
    code, no special request shape.

    <Steps>
      <Step title="Create a Proxy API key">
        1. Open **Settings → API Keys** in the [dashboard](https://app.avaliar.ai/settings/api-keys).
        2. Click **Create Key** and select the **`proxy`** scope.
        3. Copy the key. You won't be able to see it again.

        <Warning>
          Use your Avaliar key only in server-side code. Never expose it in a
          browser or client app.
        </Warning>
      </Step>

      <Step title="Add credits (or bring your own key)">
        Proxy calls run on **OpenRouter** through Avaliar. To use them you need
        either:
        - **Credits**: every org starts at **$0**; a workspace admin tops up the
          prepaid balance, **or**
        - **Your own OpenRouter key**: add it under **Settings → Organization →
          OpenRouter API Key**. When set, calls bill your OpenRouter account
          directly and credits aren't used.

        With no credits and no key, proxy calls return `402 Out of proxy credits`.
        See [BYO key & credits](/proxy/openai-compatible#credits-and-byo-key).
      </Step>

      <Step title="Point any OpenAI client at the proxy">
        Set three things on your OpenAI-compatible client/tool:
        - **Base URL:** `https://proxy-api-ckjd.onrender.com/v1`
        - **API key:** your Avaliar **proxy** key (sent as a Bearer token)
        - **Model:** an OpenRouter slug, e.g. `openai/gpt-4o`

        <CodeGroup>
          ```python OpenAI SDK (Python)
          from openai import OpenAI

          client = OpenAI(
              base_url="https://proxy-api-ckjd.onrender.com/v1",
              api_key="your-avaliar-proxy-key",
          )

          resp = client.chat.completions.create(
              model="openai/gpt-4o",
              messages=[{"role": "user", "content": "Hello!"}],
          )
          print(resp.choices[0].message.content)
          ```

          ```javascript OpenAI SDK (Node)
          import OpenAI from "openai";

          const client = new OpenAI({
            baseURL: "https://proxy-api-ckjd.onrender.com/v1",
            apiKey: "your-avaliar-proxy-key",
          });

          const resp = await client.chat.completions.create({
            model: "openai/gpt-4o",
            messages: [{ role: "user", content: "Hello!" }],
          });
          ```

          ```bash curl
          curl https://proxy-api-ckjd.onrender.com/v1/chat/completions \
            -H "Authorization: Bearer your-avaliar-proxy-key" \
            -H "Content-Type: application/json" \
            -d '{
              "model": "openai/gpt-4o",
              "messages": [{"role": "user", "content": "Hello!"}]
            }'
          ```
        </CodeGroup>

        <Info>
          Models use OpenRouter slugs (`vendor/model`), such as `openai/gpt-4o`,
          `anthropic/claude-sonnet-4-5`, `google/gemini-2.5-flash`, etc. Find
          them at [openrouter.ai/models](https://openrouter.ai/models). Detection
          runs automatically on every call. Full reference:
          [OpenAI-Compatible Endpoint](/proxy/openai-compatible).
        </Info>
      </Step>

      <Step title="View in the dashboard">
        Open [app.avaliar.ai/traces](https://app.avaliar.ai/traces) to see your
        traces, detected issues, latency, and cost in real time. A trace
        appears within a few seconds of the call.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Python SDK">
    <Steps>
      <Step title="Install the SDK">
        ```bash
        pip install "avaliar-python-sdk[local]"
        ```

        Python 3.11 or newer. The `[local]` extra adds the local models; without
        it the guard runs on rules alone.
      </Step>

      <Step title="Write your policy">
        ```bash
        avaliar init       # or: avaliar setup, the same questions in your browser
        avaliar doctor     # is everything ready?
        ```

        This writes `avaliar.yaml`, the policy your team owns, and `.avaliar/`,
        the local evidence log.
      </Step>

      <Step title="Guard your app">
        ```python
        from avaliar import Guard

        guard = Guard()                    # reads ./avaliar.yaml

        d = guard.check_input(user_message)
        if d.blocked:
            return d.reply                 # the policy's reply text
        prompt = d.text                    # original, or with [EMAIL_1]-style redactions

        answer = call_your_model(prompt)
        answer = guard.check_output(answer).text
        ```

        Guard tools with `@guard.tool`, or add one line for the
        [OpenAI Agents SDK, LangChain or MCP](/sdk/integrations).
      </Step>

      <Step title="See what happened">
        ```bash
        avaliar logs       # every decision
        avaliar verify     # check the evidence hash chains
        ```

        Everything so far runs offline and sends nothing anywhere.
      </Step>

      <Step title="Connect the dashboard (optional)">
        1. Open **Settings, API Keys** in the [dashboard](https://app.avaliar.ai/settings/api-keys).
        2. Click **Create Key** and select the **`sdk`** scope.
        3. Set it where your app runs:

        <CodeGroup>
          ```bash macOS / Linux
          export AVALIAR_API_KEY="your-key"
          ```

          ```powershell Windows (PowerShell)
          $env:AVALIAR_API_KEY = "your-key"
          ```
        </CodeGroup>

        With no code change, every decision is also uploaded and each request's
        checks appear as one trace at
        [app.avaliar.ai/traces](https://app.avaliar.ai/traces). See
        [Connecting to Avaliar Cloud](/sdk/cloud).

        <Warning>
          Store your API key securely. Treat it like a password and never commit
          it to source control.
        </Warning>
      </Step>
    </Steps>
  </Tab>
</Tabs>
