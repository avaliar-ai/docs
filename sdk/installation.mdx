## Requirements

Python **3.10** or newer.

## Install

```bash
pip install avaliar-python-sdk
```

The base install is small (tracing and blocking only: `pydantic`, `requests`, `orjson`). Optional extras add more:

| Extra | Install | Adds |
|-------|---------|------|
| `benchmarks` | `pip install "avaliar-python-sdk[benchmarks]"` | MMLU, HellaSwag, DROP, TruthfulQA, BigBenchHard, HumanEval and the BBQ, BOLD, HEx-PHI, RealToxicityPrompts evals |
| `local` | `pip install "avaliar-python-sdk[local]"` | Console output for local detection. The local detection engine itself is shared on request; see [Detection modes](/sdk/detection#detection-modes). |

## Configure

Set your API key from **Settings, API Keys** in the dashboard:

```bash
export AVALIAR_API_KEY="av_..."
```

That is all most apps need. Everything else is optional:

| Variable | Default | Description |
|----------|---------|-------------|
| `AVALIAR_API_KEY` | none | Your API key. Without it, traced functions still run and nothing is sent (one warning is logged). |
| `AVALIAR_API_URL` | Avaliar's API | Override only for a self-hosted or test backend. |
| `AVALIAR_ENVIRONMENT` | the key's environment | Tag traces `development`, `staging` or `production`. |
| `AVALIAR_TIMEOUT` | `10` | Seconds to wait for the API when sending traces. |
| `AVALIAR_BLOCKING_TIMEOUT` | `10` | Seconds the blocking prompt check may take. |
| `AVALIAR_FAIL_CLOSED` | off | `1` refuses blocking calls whose prompt could not be checked. |
| `AVALIAR_FLUSH_TIMEOUT` | `5` | Seconds to spend sending queued traces at exit. |

## First trace

```python
from avaliar import traceable
from openai import OpenAI

client = OpenAI()

@traceable("llm", model="gpt-4o", provider="openai")
def generate(messages: list):
    return client.chat.completions.create(model="gpt-4o", messages=messages)

response = generate([{"role": "user", "content": "Hello, world!"}])
```

Return the provider's response object or a string: the SDK reads the answer text and token counts from OpenAI, Anthropic, Google GenAI and LangChain responses, and joins streamed chunks.

Traces are sent from a background queue, so the traced function never waits on the network. They are flushed automatically when the process exits.

<Note>
  In serverless functions (AWS Lambda, Cloud Run jobs), call `avaliar.flush()` before the handler returns, since the process is frozen rather than exited.
</Note>

## Logging

The SDK logs to the `avaliar` logger. It warns once about problems that need you (a missing key, a rejected trace, a prompt that could not be checked) and never raises from background sending.

```python
import logging
logging.getLogger("avaliar").setLevel(logging.WARNING)
```
