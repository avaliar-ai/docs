## When to call it

After the model replies and before the user sees it. Pass the reply text, or the chat (the last assistant message is checked by default). Hallucination needs the documents the answer should rest on, as `context={"retrieval_context": [...]}`.

```python
d = guard.check_output(reply, context={"retrieval_context": docs})
return d.reply if d.blocked else d.text
```

Show `d.text`: secrets and personal data are already replaced with placeholders such as `[EMAIL_1]` where a rule redacts.

To catch a copied system prompt, plant a marker with `avaliar.new_canary()` and list it under the `data leak` rule's `canaries`, or pass the prompt as `context={"system_prompt": ...}`.

Default time budget: 1500 ms (`output.budget_ms`). A deep check, when configured, may take `judge.timeout_ms` on top unless `judge.within_budget: true`.

## The recommended preset here

| Rule | Action | Threshold |
|---|---|---|
| sensitive data | redact | category default |
| sensitive data.secrets | block | category default |
| toxicity | block | 0.85 |
| harmful content | warn | category default |
| data leak | block | 0.8 |
| hidden text | redact | 0.8 |

## Categories that can run here

| Category | Default threshold | Deep check | Needs | What it catches |
|---|---|---|---|---|
| blocklist | 0.5 | no | base install | Your own banned terms and patterns |
| copyright | 0.7 | yes | a deep check for prose | Reproduced protected text or licensed code |
| custom | 0.7 | yes | a deep check | Your own criteria in plain English (`custom.<name>` with `criteria`) |
| data leak | 0.7 | no | base install | Data leaving through links and images, and the system prompt or a canary showing up in a reply; parts `links` and `system_prompt` |
| gibberish | 0.7 | yes | a deep check for word salad | Keyboard mash, junk, token floods, word salad |
| hallucination | 0.7 | yes | `retrieval_context`; a local model or a deep check | Claims not supported by the retrieval context |
| harmful content | 0.7 | yes | a deep check | Bias, misinformation, misuse, graphic, illegal, personal safety, and personalised medical, legal or financial advice |
| hidden text | 0.5 | no | base install | Invisible or disguised characters: Unicode tags, bidi controls, zero-width runs, lookalike letters |
| language | 0.5 | no | base install | Not in the languages you allow |
| off topic | 0.85 | yes | a local model or a deep check | Outside the topics you allow |
| sensitive data | 0.5 | yes | base install | Personal data and secrets (keys, tokens, passwords); parts `personal` and `secrets` |
| toxicity | 0.8 | yes | `[local]` for the model | Abuse, harassment, threats |

See [Detectors and categories](/sdk/detection) for the detectors behind each category and [Policy file](/sdk/policy) for every rule option.
