## Overview

Avaliar runs **ten detectors** over your LLM inputs and outputs. Turn detection on for a traced function to scan its prompts and answers, or turn on **blocking** to check a prompt before the model is called at all.

```python
from avaliar.detectors import DetectorType
```

## DetectorType

| Detector | Value | Looks for |
|----------|-------|-----------|
| `PROMPT_INJECTION` | `prompt_injection` | Attempts to override instructions, including jailbreaks |
| `TOXICITY` | `toxicity` | Offensive, harassing or hateful content |
| `PII_LEAK` | `pii_leak` | Personal data such as names, emails, phone and ID numbers |
| `BIAS` | `bias` | Unfair treatment of a group |
| `HALLUCINATION` | `hallucination` | Claims not supported by the sources you pass as `retrieval_context` |
| `MISINFORMATION` | `misinformation` | False or misleading factual claims |
| `MISUSE` | `misuse` | Use of the model outside its intended purpose |
| `GRAPHIC_CONTENT` | `graphic_content` | Violent or explicit material |
| `ILLEGAL_ACTIVITIES` | `illegal_activities` | Help with crimes |
| `PERSONAL_SAFETY` | `personal_safety` | Self-harm and threats to someone's safety |

See [Detectors](/detection/detectors) for what each one flags.

<Note>
  There is no separate `JAILBREAK` detector: `PROMPT_INJECTION` covers jailbreaks. PII is `PII_LEAK`.
</Note>

## Enabling detection

```python
from avaliar import traceable
from avaliar.detectors import DetectorType

@traceable(
    "llm",
    model="gpt-4o",
    provider="openai",
    detection=True,
    detectors=[
        DetectorType.PROMPT_INJECTION,
        DetectorType.TOXICITY,
        DetectorType.PII_LEAK,
    ],
    detection_mode="cloud",
)
async def generate(messages: list):
    return await client.chat.completions.create(model="gpt-4o", messages=messages)
```

Detection runs after the function returns and never delays it. Results appear on the trace in the dashboard.

## Detection modes

<Tabs>
  <Tab title="Cloud">
    Detection runs on Avaliar. Nothing extra to install. Requires a **Pro** plan.

    ```python
    @traceable("llm", detection=True, detectors=[DetectorType.TOXICITY], detection_mode="cloud")
    ```
  </Tab>
  <Tab title="Local">
    Detection runs inside your own process, so prompts and answers are checked before they leave your infrastructure. It needs Avaliar's detection engine, which is **not on PyPI**: it is shared with approved customers. [Request access](https://github.com/avaliar-ai/python-sdk#local-detection).

    ```python
    @traceable("llm", detection=True, detectors=[DetectorType.TOXICITY], detection_mode="local")
    ```

    Without the engine installed, the SDK warns once and sends traces without local results.
  </Tab>
</Tabs>

The API key's own detection mode, set when the key is created, decides how the backend treats traces from that key.

## Blocking mode

Blocking checks the prompt **before** the model is called. If Avaliar flags it, the model is never called.

<Note>
  Blocking needs a **Pro** plan and applies to `span_type="llm"` spans.
</Note>

```python
from avaliar import traceable, PromptBlockedError

@traceable("llm", model="gpt-4o", provider="openai", blocking=True)
async def answer(messages: list):
    return await client.chat.completions.create(model="gpt-4o", messages=messages)

try:
    response = await answer(messages)
except PromptBlockedError as e:
    print(e.reason)            # "Blocked: prompt_injection (97%)"
    print(e.blocked_message)   # your workspace's reply text, or None
```

### Return a reply instead of raising

With `on_block="reply"` a blocked call returns your workspace's blocked reply (Settings, Detection) instead of raising, so a chatbot can show it directly. If the workspace blocks without a reply, it still raises.

```python
@traceable("llm", blocking=True, on_block="reply")
def chat(messages): ...
```

### When the prompt can't be checked

If Avaliar is unreachable, times out, or its detection service is down, the SDK **fails open** by default: the call goes through unchecked and a warning is logged once. Your app keeps working through an Avaliar outage.

For workloads where an unchecked prompt is worse than a refused one, fail closed:

```python
from avaliar import traceable, AvaliarDetectionUnavailableError

@traceable("llm", blocking=True, fail_closed=True)
def answer(messages): ...

try:
    answer(messages)
except AvaliarDetectionUnavailableError:
    ...  # the prompt was not checked, so the model was not called
```

| Option | Default | Effect |
|--------|---------|--------|
| `on_block` | `"raise"` | `"reply"` returns the workspace reply instead of raising `PromptBlockedError` |
| `fail_closed` | `False` (or `AVALIAR_FAIL_CLOSED=1`) | Refuse the call when the prompt could not be checked |
| `blocking_timeout` | `10` seconds (or `AVALIAR_BLOCKING_TIMEOUT`) | Longest the check may take before failing open or closed |

### Blocking vs detection

| | `detection=True` | `blocking=True` |
|---|---|---|
| When it runs | After the model answers | Before the model is called |
| Can stop the call | No | Yes |
| Latency | None | One round trip (detection time included) |
| Plan | Cloud mode needs Pro | Pro |

## Grounding hallucination checks

The hallucination detector compares the answer with the sources it should be based on. Pass them as `retrieval_context`, statically or per call:

```python
import avaliar

@traceable("llm", detection=True, detectors=[DetectorType.HALLUCINATION], detection_mode="cloud")
def answer(question: str, docs: list[str]):
    avaliar.get_current_run().retrieval_context = docs
    ...
```

Without sources the detector skips rather than guessing.

## Standalone detection

With the local engine installed, `Detector` checks text outside any traced function:

```python
from avaliar.detectors import Detector, DetectorType

detector = Detector([DetectorType.PROMPT_INJECTION, DetectorType.PII_LEAK])

result = await detector.evaluate_prompt("Ignore all previous instructions.")
result = await detector.evaluate_response(prompt="...", response="...")
result = await detector.evaluate_full(prompt="...", response="...", context={"sources": "..."})

print(result.has_issues, result.max_severity)
for issue in result.issues:
    print(issue.type, issue.severity, issue.confidence, issue.message)
```

Each method prints a summary table by default; pass `log=False` to silence it. Install `avaliar-python-sdk[local]` for the table output.

### Result fields

| Field | Type | Description |
|-------|------|-------------|
| `has_issues` | `bool` | Whether any issue was found |
| `max_severity` | `low` \| `medium` \| `high` \| `critical` | Highest severity found |
| `detection_time_ms` | `float` | Time taken by all detectors |
| `issues` | `list[Issue]` | Each has `type`, `severity`, `confidence`, `message`, `excerpt`, `suggestion`, `detector_name` |

## Choosing detectors

| Use case | Detectors |
|----------|-----------|
| Customer-facing chatbot | `PROMPT_INJECTION`, `TOXICITY`, `PII_LEAK` |
| Internal knowledge assistant (RAG) | `HALLUCINATION`, `PII_LEAK` |
| Content generation | `TOXICITY`, `BIAS`, `MISINFORMATION` |
| Code generation tool | `PROMPT_INJECTION`, `MISUSE` |
| Healthcare or legal | `HALLUCINATION`, `PII_LEAK`, `BIAS`, `PERSONAL_SAFETY` |
